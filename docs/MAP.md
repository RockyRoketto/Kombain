## Как устроено

Один exe: локальный HTTP-сервер на `127.0.0.1:47831` и окно WebView2, которое показывает страницу с этого сервера.
Страница каждые 700 мс опрашивает `/api/state` и перерисовывает то, что изменилось. Вся работа — запуск `ffmpeg` с разобранным stdout (`-progress`).

Путь пачки: `/api/start` → `Server.begin` (занять программу) → `run` (имена результатов, очередь) → `convert` на каждый файл → `runFF` или `encodeTarget`. Статусы лежат в `Server.files`, под `Server.mu`.

## Интерфейс: web/

Страница собирается в один HTML при запуске (`web.go`): `index.html` + `style.css` + скрипты по порядку из `webJS`.

## HTTP API

Все ручки `/api/*` требуют заголовок `X-Token` и правильный Host, описаны в `routes` (`api.go`).

| Группа | Ручки |
|---|---|
| Пачка | `start`, `banners`, `banner-dirs`, `cancel`, `state` |
| Звуки | `sounds`, `pick-sound` |
| Файлы | `pick-files`, `pick-folder`, `project-save`, `project-open`, `subs-pick`, `subs-read`, `subs-save`, `favicon-save`, `fav-read`, `pdf-pick`, `pdf-list`, `pdf-info`, `pdf-estimate`, `pdf-page-marks`, `pdf-compare`, `pdf-run`, `pdf-ras-begin`, `pdf-page-save`, `pdf-ras-end`, `whisper-info`, `whisper-start`, `whisper-state`, `whisper-cancel`, `fonts`, `text-png`, `upload`, `discard`, `info`, `proxy`, `proxy-stop`, `proxy-usage`, `proxy-clear`, `snapshot`, `snapshot-montage`, `open-output`, `open-dir`, `open-data`, `open-file` |
| ffmpeg | `download-ffmpeg`, `ffmpeg-skip` |
| Фигуры | `shape-seq` (кадры прорисовки линии: страница шлёт PNG, Go кладёт `seq-<сумма>-%04d.png` в кэш текста, `shapes.go`) |
| Картинки | `gen-info`, `gen-add`, `gen-state`, `gen-cancel`, `gen-clear` (`genapi.go`), `gen-copy-text` (`gengallery.go`, текст в буфер через `copyText`); установка `ai-setup`, `ai-root`, `ai-install`, `ai-cancel`, `ai-remove`, `ai-license`, промт от помощника `gen-enhance` (`aisetup.go`); галерея `gen-gallery`, `gen-fav`, `gen-delete`, `gen-reveal`, `gen-restore`, `gen-export`, `gen-copy` (`gengallery.go`); миниатюра вне `/api`: `/gen-thumb?t=…&p=…`; кадр предпросмотра вне `/api`: `/gen-frame?t=…&id=…` |
| Программа | `settings`, `app-update`, `app-skip`, `news-seen`, `install`, `setup-later`, `exit`, `storage`, `storage-clear`, `storage-remove` |

Вне `/api`: `/` (страница), `/favicon.png`, `/thumb`, `/wave` и `/media`, `/gen-frame` и `/gen-thumb` (токен в параметре `t`). Адреса картинок в `index.html` содержат метку `__VER__`, её подставляет `routes`: иначе после обновления окно показывает старые из кэша.
